# uaice cream

Site de apresentação do **trabalho de marketing** da Universidade de Uberaba (2026): planejamento de marketing para o lançamento da **uaice fit**, linha de picolés fit recheados da uaice cream, marca fictícia.

O site é uma página única: capa com o grupo, produto, análise de mercado, SWOT, público-alvo, catálogo com carrinho de demonstração, objetivos, 4 Ps, logística, investimento inicial estimado, promoção, monitoramento e referências.

## Como abrir

É um único arquivo HTML, sem dependências de build. Abra o `index.html` no navegador ou publique pelo GitHub Pages (Settings → Pages → branch `main`).

## Avisos

- uaice cream é uma marca fictícia, e a parceria com a Coca-Cola também é fictícia.
- O carrinho é apenas demonstrativo: nada é cobrado.
- Os valores de investimento são estimativas do grupo para o exercício, não um cálculo contábil.
